# Enterprise Architect Add-In

`planttoxmi` includes an optional Sparx Enterprise Architect Add-In for Windows.

The Add-In provides:

```text
PlantToXMI
  Import PlantUML...
  Validate planttoxmi Installation
  About
```

It is a GUI and Automation bridge only. PlantUML parsing, UML model generation,
XMI serialization, and validation remain in the Python `planttoxmi` CLI.

See `ea-addin/README.md` for build, registration, configuration, and
troubleshooting instructions.
